# Course 2 — Play It Safe: Manage Security Risks

## Overview

I completed the second course of the Google Cybersecurity Professional Certificate.

This course helped me understand security risks and how organizations identify, assess, and manage those risks.

## Topics I Learned

- Security risks
- Risk management
- Threats and vulnerabilities
- Security controls
- Administrative and technical controls
- Security frameworks
- NIST Cybersecurity Framework
- Security policies
- Risk assessment
- Incident response concepts

## Key Learning

I learned that cybersecurity is not only about detecting attacks. Organizations also need to identify potential risks and implement appropriate security controls to reduce those risks.

## My Takeaway

This course helped me understand how cybersecurity professionals approach risk and why security policies, controls, and frameworks are important for protecting organizations.
