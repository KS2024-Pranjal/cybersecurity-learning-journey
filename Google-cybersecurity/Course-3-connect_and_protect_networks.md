## Overview

I completed the third course of the Google Cybersecurity Professional Certificate.

This course introduced me to computer networks and the importance of protecting network infrastructure.

## Topics I Learned

- Network fundamentals
- Network communication
- Network protocols
- TCP/IP
- IP addresses
- Network security
- Network vulnerabilities
- Common network attacks

- Network security controls
- Security monitoring concepts

I learned how devices communicate over networks and why network security is an important part of cybersecurity.

Understanding networking provides an important foundation for identifying and responding to security threats.

This course improved my understanding of networks and helped me connect networking concepts with cybersecurity.
